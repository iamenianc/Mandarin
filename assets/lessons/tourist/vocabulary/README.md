# Vocabulary

The tourist vocabulary lessons: the travel themes from ADR 0008, taught as sound,
pinyin, and meaning. Lesson numbers continue the vocabulary module sequence that
begins with the beginner themes, so the module reads as one course across levels.

## Sequence

| Lesson | Theme |
| --- | --- |
| `vocabulary-05-ordering-food.md` | Ordering food |
| `vocabulary-06-directions.md` | Directions |
| `vocabulary-07-transport.md` | Transport |
| `vocabulary-08-hotel.md` | Hotel |
| `vocabulary-09-shopping.md` | Shopping |

Each lesson favours whole phrases that can be used in the field, not isolated words
alone (ADR 0008).
