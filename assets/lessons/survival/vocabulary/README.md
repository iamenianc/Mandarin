# Vocabulary

The survival vocabulary lessons close the vocabulary module sequence that begins at
the beginner level. They cover the two themes a beginner needs most when something
goes wrong: emergencies and repair phrases.

## Sequence

| Lesson | Theme |
| --- | --- |
| `vocabulary-10-emergencies.md` | Emergencies |
| `vocabulary-11-repair.md` | Repair phrases |

Each item is taught as a complete spoken unit, because these phrases are used when
there is no time to assemble them.
