# Listening

The listening module lessons: hear-and-name teaching before the reps move to
practice. Each lesson plays one short clip and asks the learner to name what was
heard from large, low-attention controls (ADR 0008, `docs/03-design.md`). No speech
is required, so the lessons work offline.

## Sequence

| Lesson | Title | Response |
| --- | --- | --- |
| `listening-01-hear-the-tone.md` | Hear the tone | Name the tone number |
| `listening-02-hear-the-word.md` | Hear the word | Choose the matching pinyin or meaning |

Clips are the bundled reference audio for the items taught in the tones and vocabulary
modules (ADR 0006, ADR 0010).
