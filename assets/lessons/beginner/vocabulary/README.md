# Vocabulary

The beginner vocabulary lessons: high-frequency words and phrases taught as sound,
pinyin, and meaning, with no hanzi (ADR 0008, ADR 0011). The module continues at the
tourist and survival levels, and lesson numbers sequence it across all levels.

## Sequence

| Lesson | Theme |
| --- | --- |
| `vocabulary-01-greetings.md` | Greetings |
| `vocabulary-02-courtesy.md` | Courtesy |
| `vocabulary-03-numbers.md` | Numbers |
| `vocabulary-04-time.md` | Time |

Each item is heard, then shown as pinyin with tone numbers and an English meaning.
