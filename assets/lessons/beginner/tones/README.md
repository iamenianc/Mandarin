# Tones

The tones module lessons, taught beginner-first: one tone at a time, heard as a
contour and labelled with its tone number, then tone pairs (ADR 0008, ADR 0012).

## Sequence

| Lesson | Title | Topic |
| --- | --- | --- |
| `tones-01-first-tone.md` | First tone | High, level contour |
| `tones-02-second-tone.md` | Second tone | Rising contour |
| `tones-03-third-tone.md` | Third tone | Dipping contour |
| `tones-04-fourth-tone.md` | Fourth tone | Falling contour |
| `tones-05-neutral-tone.md` | Neutral tone | Short and light, no fixed contour |
| `tones-06-tone-pairs.md` | Tone pairs | Two-syllable combinations |

Tone numbers are written after the syllable (`ma1` to `ma5`) wherever a tone is named
(ADR 0012). Every item is heard before it is labelled. The contour diagram
`diagrams/tone-contours.svg` supports the one-tone-at-a-time lessons.
