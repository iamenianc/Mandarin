# Second tone

| Field | Value |
| --- | --- |
| id | tones-02-second-tone |
| module | tones |
| lesson | 02 |
| level | beginner |
| topic | tone contours |

The second tone rises. It starts low and moves upward, and it is written with tone
number 2 after the syllable. The learner hears the rise before it is named.

## Items

| # | pinyin | contour |
| --- | --- | --- |
| 1 | ma2 | rising |
| 2 | shi2 | rising |
| 3 | lai2 | rising |

## Notes

- The rise is heard against a steady reference pitch, not against another tone.
- Reference audio is generated at build time from the pinyin above and bundled under
  `assets/audio/` (ADR 0006).
