# Beginner

The entry level of the curriculum: the sound system first, then the first words
(ADR 0008). Tones are taught before vocabulary, and every lesson stays audio-first
with pinyin shown and tone numbers written after each syllable (ADR 0011, ADR 0012).

## Modules

| Folder | Module | Focus |
| --- | --- | --- |
| `tones/` | tones | The four tones and the neutral tone, then tone pairs |
| `fundamentals/` | fundamentals | Syllable anatomy, initials, finals, notation, sandhi |
| `vocabulary/` | vocabulary | Greetings, courtesy, numbers, and time |
| `listening/` | listening | Hear-and-name lessons |
| `speech/` | speech | Say-and-repeat lessons |

Practice sets reuse the items taught here; a lesson is guided teaching and contains
no reps. Reference audio is generated at build time from the pinyin (ADR 0006).
