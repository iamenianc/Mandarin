# Fundamentals

The fundamentals module lessons: how Mandarin sound is built, taught by ear with
pinyin as the sound map (ADR 0008, ADR 0011). Theory is heard as examples, never read
as grammar text.

## Sequence

| Lesson | Title | Topic |
| --- | --- | --- |
| `fundamentals-01-syllable-anatomy.md` | Syllable anatomy | Initial, final, and tone |
| `fundamentals-02-initials.md` | Initials | The consonants that open a syllable |
| `fundamentals-03-finals.md` | Finals | The vowels that carry a syllable |
| `fundamentals-04-tone-numbers.md` | Tone numbers | The notation used everywhere |
| `fundamentals-05-tone-sandhi.md` | Tone sandhi | How tones change in context |

Each lesson names one idea and gives heard examples; repetition belongs to practice.
