# Vocabulary reference clips

Reference audio for the vocabulary module: audio-first words and phrases over the
beginner, tourist, and survival themes in ADR 0008 (greetings and courtesy, numbers and
money, ordering food, directions and transport, hotel, shopping, time, emergencies).

## Clip set

- One clip per word or phrase, heard and spoken rather than read.
- Phrase clips that exercise a full target tone sequence.
- Alternate-voice variants for the same item, using the `-<voice>` suffix.

## Metadata

- `pinyin` is always present with tone numbers; `meaning` is the English gloss.
- `hangul` is optional and never required (ADR 0004).
- `contentType` is `word` or `phrase`; `targetTones` lists the expected tones.
- No hanzi appears in a file name or an entry (ADR 0002).
