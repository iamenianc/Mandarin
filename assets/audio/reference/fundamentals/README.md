# Fundamentals reference clips

Reference audio for the fundamentals module: syllable anatomy (initial and final), the
pinyin sound system, tone sandhi, rhythm, and stress, taught by ear (ADR 0008, ADR 0012).

## Clip set

- Minimal pairs that isolate one initial or final.
- Sandhi examples where a tone changes in connected speech.
- Read-aloud items used as the target for pinyin reading practice (ADR 0011).
- Rhythm and stress examples.

## Metadata

- `contentType` is `minimalPair` or `phrase`; `pinyin` carries tone numbers.
- `meaning` may be omitted for a pure sound contrast, but `pinyin` is always present.
- `hangul` is optional; no hanzi anywhere (ADR 0002, ADR 0004).
