# Directions and transport

Phrases for asking the way and using local transport (ADR 0008). The single
lines here are put into a full exchange in `directions-asking-dialogue.md`.

| pinyin | meaning | note |
| --- | --- | --- |
| `huo3 che1 zhan4 zai4 na3 li3` | where is the train station? | |
| `di4 tie3 zhan4` | subway station | |
| `gong1 jiao1 che1` | bus | |
| `chu1 zu1 che1` | taxi | |
| `wo3 yao4 qu4 huo3 che1 zhan4` | I want to go to the train station | |
| `wang3 zuo3 zou3` | turn left | |
| `wang3 you4 zou3` | turn right | |
| `yi4 zhi2 zou3` | go straight | `yi1` is spoken as `yi4` before a second tone. |
| `ran2 hou4` | then | |
| `zhe4 li3` | here | |
| `na4 li3` | there | |
| `li2 zhe4 li3 yuan3 ma5` | is it far from here? | |
| `duo1 yuan3` | how far? | |
| `wo3 yao4 xia4 che1` | I want to get off | |
| `dao4 le5` | arrived | |
