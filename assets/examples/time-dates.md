# Time and dates

Phrases for telling the time and naming days and parts of the day (ADR 0008).

| pinyin | meaning | note |
| --- | --- | --- |
| `xian4 zai4 ji3 dian3` | what time is it now? | |
| `xian4 zai4 san1 dian3` | it is three o'clock now | |
| `san1 dian3 ban4` | half past three | |
| `xing1 qi1 yi1` | Monday | Weekdays are `xing1 qi1` plus a number. |
| `xing1 qi1 liu4` | Saturday | |
| `xing1 qi1 ri4` | Sunday | `xing1 qi1 tian1` is also common. |
| `jin1 tian1` | today | |
| `ming2 tian1` | tomorrow | |
| `zuo2 tian1` | yesterday | |
| `shang4 wu3` | morning | The part of the day before noon. |
| `xia4 wu3` | afternoon | |
| `wan3 shang5` | evening | The second syllable is neutral. |
| `duo1 chang2 shi2 jian1` | how long? | |
| `wo3 chi2 dao4 le5` | I am late | |
| `ming2 tian1 jian4` | see you tomorrow | |
