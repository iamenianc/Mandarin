# Numbers and money

Counting and payment phrases. Numbers are taught audio-first, and the forms here
are the everyday ones a beginner needs (ADR 0008).

| pinyin | meaning | note |
| --- | --- | --- |
| `ling2` | zero | |
| `yi1` | one | |
| `er4` | two | |
| `san1` | three | |
| `si4` | four | |
| `wu3` | five | |
| `liu4` | six | |
| `qi1` | seven | |
| `ba1` | eight | |
| `jiu3` | nine | |
| `shi2` | ten | |
| `yi4 bai3` | one hundred | `yi1` is spoken as `yi4` before a third tone. |
| `yi4 qian1` | one thousand | `yi1` is spoken as `yi4` before a first tone. |
| `liang3` | two (of something) | Used before a measure word instead of `er4`. |
| `duo1 shao5 qian2` | how much money? | |
| `tai4 gui4 le5` | too expensive | |
| `pian2 yi5` | cheap | The second syllable is neutral. |
| `ke3 yi3 pian2 yi5 yi4 dian3 ma5` | can it be a little cheaper? | `yi1` is spoken as `yi4` before a third tone. |
| `wo3 yao4 zhe4 ge5` | I want this one | |
| `ke3 yi3 shua1 ka3 ma5` | can I pay by card? | |
| `wo3 yong4 xian4 jin1` | I will use cash | |
