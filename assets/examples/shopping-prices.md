# Shopping and prices

Phrases for asking prices, comparing, and buying (ADR 0008). The single lines
here are put into a full exchange in `shopping-bargaining-dialogue.md`.

| pinyin | meaning | note |
| --- | --- | --- |
| `zhe4 ge5 duo1 shao5 qian2` | how much is this? | |
| `tai4 gui4 le5` | too expensive | |
| `you3 pian2 yi5 de5 ma5` | do you have a cheaper one? | |
| `ke3 yi3 pian2 yi5 yi4 dian3 ma5` | can it be a little cheaper? | `yi1` is spoken as `yi4` before a third tone. |
| `wo3 kan4 kan5` | let me look | The second syllable is neutral. |
| `ke3 yi3 shi4 shi5 ma5` | can I try it? | The second syllable is neutral. |
| `wo3 yao4 zhe4 ge5` | I will take this one | |
| `bu2 yao4` | I do not want it | `bu4` is spoken as `bu2` before a fourth tone. |
| `you3 mei2 you3 bie2 de5 yan2 se4` | do you have another colour? | |
| `wu3 shi2 kuai4` | fifty yuan | `kuai4` is the colloquial word for the yuan. |
| `si4 shi2 wu3` | forty-five | |
| `jiu4 zhe4 ge5` | this one then | Marks a decision after choosing. |
