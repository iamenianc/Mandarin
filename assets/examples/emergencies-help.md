# Emergencies and help

Phrases for asking for help when something goes wrong (ADR 0008). The single
lines here are put into a full exchange in `emergencies-reporting-dialogue.md`.

| pinyin | meaning | note |
| --- | --- | --- |
| `jiu4 ming4` | help! | Urgent call for help. |
| `bang1 bang5 wo3` | help me | The second syllable is neutral. |
| `qing3 bang1 wo3` | please help me | |
| `wo3 xu1 yao4 yi1 sheng1` | I need a doctor | |
| `yi1 yuan4 zai4 na3 li3` | where is the hospital? | |
| `kuai4 jiao4 jiu4 hu4 che1` | call an ambulance quickly | |
| `jing3 cha2` | police | |
| `jiao4 jing3 cha2` | call the police | |
| `wo3 mi2 lu4 le5` | I am lost | |
| `wo3 de5 qian2 bao1 diu1 le5` | I lost my wallet | |
| `wo3 sheng1 bing4 le5` | I am sick | |
| `wo3 gan3 jue2 bu4 shu1 fu5` | I do not feel well | The last syllable is neutral. |
| `bie2 ji2` | do not worry | |
| `man4 man5 shuo1` | speak slowly | The second syllable is neutral. |
| `gen1 wo3 lai2` | come with me | |
| `wo3 men5 qu4 jing3 cha2 ju2` | we will go to the police station | `men5` is the neutral plural marker. |
