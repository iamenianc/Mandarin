# Hotel stays

Phrases for checking in, room needs, and checking out (ADR 0008). The single
lines here are put into a full exchange in `hotel-checkin-dialogue.md`.

| pinyin | meaning | note |
| --- | --- | --- |
| `wo3 you3 yu4 ding4` | I have a reservation | |
| `wo3 yao4 yi2 ge5 fang2 jian1` | I would like a room | `yi1` is spoken as `yi2` before a fourth tone. |
| `you3 mei2 you3 kong4 fang2` | do you have a vacancy? | |
| `duo1 shao5 qian2 yi4 wan3` | how much per night? | `yi1` is spoken as `yi4` before a third tone. |
| `fang2 jian1 li3 you3 wang3 luo4 ma5` | is there internet in the room? | |
| `zao3 can1 ji3 dian3` | what time is breakfast? | |
| `qing3 huan4 yi2 ge5 fang2 jian1` | please change to another room | |
| `wo3 yao4 tui4 fang2` | I would like to check out | |
| `zao3 can1` | breakfast | |
| `wu3 can1` | lunch | |
| `wan3 can1` | dinner | |
