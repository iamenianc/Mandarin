# Ordering food

Phrases for ordering, dietary needs, and paying at a restaurant (ADR 0008).
The single lines here are put into a full exchange in
`ordering-food-dialogue.md`.

| pinyin | meaning | note |
| --- | --- | --- |
| `cai4 dan1` | menu | |
| `qing3 gei3 wo3 cai4 dan1` | please give me the menu | |
| `ji3 wei4` | how many people? | Host's question; `wei4` is a polite counter for people. |
| `wo3 yao4 zhe4 ge5` | I will have this one | |
| `yi4 bei1 shui3` | a glass of water | `yi1` is spoken as `yi4` before a first tone. |
| `yi4 bei1 cha2` | a cup of tea | `yi1` is spoken as `yi4` before a first tone. |
| `hao3 chi1` | delicious | |
| `wo3 chi1 bao3 le5` | I am full | |
| `bu2 yao4 la4` | not spicy | `bu4` is spoken as `bu2` before a fourth tone. |
| `wo3 bu4 chi1 rou4` | I do not eat meat | |
| `su4 shi2` | vegetarian food | |
| `qing3 jie2 zhang4` | please bring the bill | |
| `mai3 dan1` | pay the bill | Colloquial way to ask for the bill. |
