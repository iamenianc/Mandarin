# Ordering at a restaurant

A guest orders and the server confirms. Uses the phrases in `ordering-food.md`.

| speaker | pinyin | meaning |
| --- | --- | --- |
| Server | `nin2 hao3, qing3 wen4 ji3 wei4?` | hello, how many people? |
| Guest | `liang3 wei4.` | two people. |
| Server | `qing3 zuo4.` | please sit. |
| Guest | `xie4 xie5. you3 cai4 dan1 ma5?` | thank you. do you have a menu? |
| Server | `you3, gei3 nin2.` | yes, here you are. |
| Guest | `wo3 yao4 yi4 bei1 cha2, yi2 ge5 chao3 fan4.` | I would like a tea and a fried rice. |
| Server | `hao3 de5.` | all right. |
