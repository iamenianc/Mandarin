## Conventions

- Treat culture as context for language, not as a fixed rulebook. Customs vary by region,
  generation, and setting, and the notes say so where it matters.
- Keep descriptions specific and observable; avoid broad claims about a "national
  character".
- Write culture notes as authoring guidance and as candidate content for Raymond, not as
  learner-facing lessons.
- No hanzi anywhere (ADR 0002); culture terms appear as pinyin with tone numbers.
- When a custom could cause offence if misapplied, mark it clearly.
