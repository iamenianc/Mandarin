# Names and address

How names are ordered and how people are addressed.

## Name order

A Chinese name puts the surname first, then the given name. Most names are two or three
syllables in total: a one-syllable surname plus a one- or two-syllable given name.

| Pinyin | Notes |
| --- | --- |
| `Li3` | common surname |
| `Wang2` | common surname |
| `Zhang1` | common surname |
| `Liu2` | common surname |
| `Chen2` | common surname |

A full name such as `Wang2 Ming2` is surname `Wang2` plus given name `Ming2`.

## Forms of address

| Pinyin | English | Use |
| --- | --- | --- |
| `Wang2 xian1sheng5` | Mr Wang | formal, surname plus title |
| `Li3 nü3shi4` | Ms Li | formal |
| `Li3 lao3shi1` | Teacher Li | school setting |
| `lao3ban3` | boss / shopkeeper | addressing a proprietor |
| `Ming2` | given name | friends, family, peers only |
| `xiao3 Wang2` | young Wang | familiar, often at work |

Using a given name with a stranger can feel too familiar; title plus surname is the safe
default.

## Kinship terms as address

Kinship words extend to non-relatives as warm, respectful address:

| Pinyin | English | Use |
| --- | --- | --- |
| `a1yi2` | auntie | an older woman |
| `shu1shu5` | uncle | an older man |
| `ge1ge5` | elder brother | a peer, warmly |
| `jie3jie5` | elder sister | a peer, warmly |

## Authoring notes

- Keep surname plus title in generated dialogues between strangers.
- Use kinship address for friendly service interactions, such as calling a shopkeeper
  `lao3ban3` or an older helper `a1yi2`.
- Do not put a given name before the surname; Chinese name order is the reverse of English.
