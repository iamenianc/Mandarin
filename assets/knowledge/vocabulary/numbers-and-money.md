# Numbers and money

Counting to large numbers, the two words for "two", and the money language for prices and
payment.

## Numbers

| Pinyin | Value |
| --- | --- |
| `ling2` | 0 |
| `yi1` | 1 |
| `er4` | 2 |
| `san1` | 3 |
| `si4` | 4 |
| `wu3` | 5 |
| `liu4` | 6 |
| `qi1` | 7 |
| `ba1` | 8 |
| `jiu3` | 9 |
| `shi2` | 10 |
| `shi2 yi1` | 11 |
| `er4 shi2` | 20 |
| `er4 shi2 yi1` | 21 |
| `san1 shi2 wu3` | 35 |
| `jiu3 shi2 jiu3` | 99 |
| `yi1 bai3` | 100 |
| `yi1 bai3 ling2 yi1` | 101 |
| `yi1 qian1` | 1,000 |
| `yi1 wan4` | 10,000 |
| `liang3` | two (before a measure word) |

Numbers are built by place, largest to smallest, with `ling2` filling a skipped place.

| `san1 kuai4 wu3` | 3.50 yuan |

## Authoring notes

- Use `liang3`, not `er4`, before a measure word: `liang3 kuai4` (two yuan).
- Keep `kuai4` for speech and `yuan2` for written or formal prices.
- Money drills pair well with the numbers module and the shopping theme.
