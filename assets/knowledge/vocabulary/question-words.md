## Example questions

| Pinyin | English |
| --- | --- |
| `ni3 jiao4 shen2me5 ming2zi5` | what is your name? |
| `ta1 shi4 shei2` | who is he? |
| `ni3 qu4 na3li3` | where are you going? |
| `ni3 shen2me5 shi2hou5 lai2` | when are you coming? |
| `wei4 shen2me5` | why? |
| `zhe4 ge5 duo1shao5 qian2` | how much is this? |
| `zen3me5 zou3` | how do we get there? |
| `ji3 ge5 ren2` | how many people? |

## Authoring notes

- Use `ji3` with a measure word for small counts and `duo1shao5` for open quantities.
- Never add `ma5` to a sentence that already contains a question word.
- `zen3me5 yang4` also works as a greeting-style check-in: `ni3 zen3me5 yang4` (how are
  you doing?).
