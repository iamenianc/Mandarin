beginner, tourist, and survival themes in ADR 0008. Each entry is pinyin with tone numbers
plus an English meaning, with a short usage note where it helps authoring.

## Conventions

- No hanzi anywhere (ADR 0002); every entry is pinyin plus an English meaning.
- Tones are written as numbers after each syllable, with `5` for the neutral tone
  (ADR 0012).
- Use `liang3` before measure words and `er4` when counting, in dates, and in numbers.
- Prefer high-frequency senses; add a note only when it shows real usage.
- Hangul is an optional aid inside the app and is not authored here.
- Keep a word in one theme file only, and cross-reference related files instead of copying
  entries.
