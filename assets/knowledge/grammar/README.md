# Grammar

Sentence patterns and the particles that hold Mandarin together. These notes exist so
authored and generated items use structures that are correct for the level and are built
from content the modules already teach.

| File | Topic |
| --- | --- |
| `word-order.md` | The base sentence and where adverbs, time, and place go |
| `pronouns-and-people.md` | Pronouns, plurals, possession, demonstratives |
| `noun-phrases.md` | Modifiers, measure words, and the particle `de5` |
| `question-forms.md` | Yes / no, A-not-A, and question-word questions |
| `negation.md` | `bu4`, `mei2`, `bie2`, and when each applies |
| `measure-words.md` | Classifiers for counting and pointing |
| `aspect-markers.md` | `le5`, `guo5`, `zhe5`, and progressive forms |
| `comparison.md` | `bi3`, equality, and superlatives |
| `modal-verbs.md` | Ability, permission, want, and obligation |
| `time-and-place.md` | Time expressions, location, and duration |
| `verb-complements.md` | Result, direction, potential, and manner |
| `conjunctions-and-connectors.md` | Linking words and paired structures |

Examples carry tone numbers on every syllable (`ni3 hao3`) and never use hanzi (ADR 0002,
ADR 0012). Grammar is taught by ear and in context; these notes are authoring reference,
not lesson text (see ADR 0008).
