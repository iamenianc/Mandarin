# Pronouns and people

Pronouns do not change for case or gender. Plurals add `men5`, and possession adds `de5`.

## Personal pronouns

| Pinyin | English | Notes |
| --- | --- | --- |
| `wo3` | I / me | |
| `ni3` | you (singular) | |
| `nin2` | you (polite) | used with strangers, elders, customers |
| `ta1` | he / she / it | one spoken form for all three |
| `wo3men5` | we / us | |
| `ni3men5` | you (plural) | |
| `ta1men5` | they / them | |

`ta1` does not distinguish gender in speech; only writing would, and the app writes
pinyin only (ADR 0002).

## Possession

Add `de5` to the pronoun. For close relationships and a few fixed phrases, `de5` is often
dropped.

| Pinyin | English |
| --- | --- |
| `wo3 de5 che1` | my car |
| `ni3 de5 shu1` | your book |
| `ta1 de5 ming2zi5` | his / her name |
| `wo3 ma1ma5` | my mother |
| `wo3men5 xue2xiao4` | our school |

`de5` also stands alone for "mine / yours": `zhe4 shi4 wo3 de5` (this is mine).

## Demonstratives

| Pinyin | English | Notes |
| --- | --- | --- |
| `zhe4` | this | used before a measure word |
| `na4` | that | used before a measure word |
| `zhe4 ge5` | this one | |
| `na4 ge5` | that one | |
| `zhe4li3` / `zhe4r` | here | `zhe4r` is the northern colloquial form |
| `na4li3` / `na4r` | there | |
| `na3li3` / `na3r` | where | question word, see `question-forms.md` |

## Other people words

| Pinyin | English |
| --- | --- |
| `da4jia1` | everyone |
| `zi4ji3` | oneself |
| `bie2ren2` | other people |
| `zan2men5` | we (including the listener) |
| `ren2` | person / people |

## Authoring notes

- Default to `ni3`; use `nin2` when the register is formal or the addressee is a stranger.
- `men5` marks people only, so `san1 ge5 xue2sheng5` (three students) does not take it.
- Keep `ta1` gender-neutral in generated content; the meaning comes from context.
