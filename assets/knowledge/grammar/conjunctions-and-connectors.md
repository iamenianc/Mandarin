# Conjunctions and connectors

Connectors join words or clauses. Several come in fixed pairs, with the first half early
in the sentence and the second half before the result or the contrast.

## Joining words

| Pinyin | English | Notes |
| --- | --- | --- |
| `he2` | and | nouns and noun phrases |
| `gen1` | and / with | people, often "together with" |
| `huo4zhe3` | or | statements |
| `hai2shi5` | or | questions only |
| `yi1qi3` | together | `wo3 gen1 ni3 yi1qi3 qu4` |

`he2` and `gen1` do not join clauses; start a new sentence instead.

## Common adverbs as connectors

| Pinyin | English |
| --- | --- |
| `ye3` | also |
| `dou1` | all, both |
| `hai2` | also, still |
| `you4` | again (past), also |
| `zai4` | again (future), then |
| `jiu4` | then, right away |

| Pinyin | English |
| --- | --- |
| `wo3 ye3 yao4` | I want one too |
| `ta1men5 dou1 lai2 le5` | they have all come |
| `wo3 you4 lai2 le5` | I am back again |
| `zai4 shuo1 yi1 bian4` | say it again |

## Paired structures

| Pattern | Pinyin | English |
| --- | --- | --- |
| because ... so | `yin1wei4 ... suo3yi3 ...` | `yin1wei4 xia4 yu3, suo3yi3 wo3 bu2 qu4` - because it is raining, I am not going |
| although ... but | `sui1ran2 ... dan4shi4 ...` | `sui1ran2 mang2, dan4shi4 hen3 hao3` - although busy, it is fine |
| if ... then | `ru2guo3 ... jiu4 ...` | `ru2guo3 ni3 lai2, wo3 jiu4 qu4` - if you come, I will go |
| not only ... but also | `bu2dan4 ... er2qie3 ...` | `bu2dan4 gui4, er2qie3 bu4 hao3` - not only expensive, but also not good |
| first ... then | `xian1 ... ran2hou4 ...` | `xian1 chi1 fan4, ran2hou4 zou3` - eat first, then go |
| while ... while | `yi1bian1 ... yi1bian1 ...` | `yi1bian1 zou3 yi1bian1 shuo1` - talk while walking |
| more ... more | `yue4 ... yue4 ...` | `yue4 kuai4 yue4 hao3` - the faster the better |

In each pair, only one half is needed if the relationship is clear, but the pair is the
default in careful speech.

## Standalone connectors

| Pinyin | English |
| --- | --- |
| `dan4shi4` | but |
| `ke3shi4` | but |
| `bu2guo4` | however |
| `suo3yi3` | so |
| `ran2hou4` | then |
| `er2qie3` | moreover |
| `hai2you3` | and also |
| `ye3 xu3` | perhaps |

| Pinyin | English |
| --- | --- |
| `wo3 hen3 lei4, dan4shi4 hen3 gao1xing4` | I am tired, but happy |
| `jin1tian1 xia4 yu3, suo3yi3 wo3 bu2 qu4` | it is raining today, so I am not going |
| `wo3 yao4 cha2, hai2you3 shui3` | I want tea, and also water |

## Authoring notes

- Keep paired structures paired; a lone `yin1wei4` without a result clause reads as
  incomplete.
- Use `hai2shi5` only in questions and `huo4zhe3` in statements.
- Keep `he2` and `gen1` to nouns; joining whole clauses needs a sentence break or a
  connector such as `ran2hou4`.
