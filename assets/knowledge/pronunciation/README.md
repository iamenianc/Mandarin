# Pronunciation

How Mandarin sound is built and written in the app's pinyin notation. Tones, syllable
anatomy, the pinyin sound system, tone sandhi, and rhythm, for authoring the tones and
fundamentals modules and for writing accurate `targetTones`.

| File | Topic |
| --- | --- |
| `tone-numbers.md` | The tone-number notation used everywhere in the app |
| `tone-contours.md` | The four tones and the neutral tone, by pitch contour |
| `tone-sandhi.md` | How tones change in context, and how display stays consistent |
| `syllable-anatomy.md` | Initial, final, and tone; the parts of a syllable |
| `initials.md` | The 21 initials and the y / w spellings |
| `finals.md` | Simple, compound, and nasal finals |
| `spelling-conventions.md` | Pinyin shorthand, the umlaut, and zero-initial spellings |
| `rhythm-and-stress.md` | Syllable timing, the neutral tone, and phrase rhythm |
| `minimal-pairs.md` | Tone and segmental contrasts for discrimination drills |

Pinyin always carries tone numbers (ADR 0012): `ni3 hao3`, with the neutral tone written
as `5` (`ma5`). No hanzi appears in this folder (ADR 0002).
