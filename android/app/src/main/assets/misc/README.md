# General assets

General or miscellaneous supporting data that is not configuration, legal, or branding.
Keep this folder small and purposeful.

| File | Purpose |
| --- | --- |
| `app-identity.json` | Canonical app identity for the About/settings surface and tooling |

## Rules

- No secrets, no learning content, no structured `res/` resources.
- Prefer an existing folder (`config/`, `legal/`, `branding/`) when a file has a clear
  home there.
